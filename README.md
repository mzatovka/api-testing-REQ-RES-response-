# API Testing — ReqRes

Автоматизированное тестирование REST API сервиса **ReqRes** с использованием Python, `pytest` и библиотеки `requests`.

Проект предназначен для практики API-тестирования и проверки корректности HTTP-запросов и ответов API.

## Стек

* **Python** — язык программирования
* **pytest** — фреймворк для написания и запуска автотестов
* **Requests** — HTTP-клиент для отправки API-запросов
* **ReqRes** — REST API, используемый в качестве тестового стенда
* **Git / GitHub** — система контроля версий и хранения проекта

Основное внимание в тестах уделено проверке HTTP-методов, статус-кодов и содержимого JSON-ответов. Проверка HTTP response является одной из базовых задач API-тестирования.

## Что тестируется

В проекте проверяются основные сценарии взаимодействия с API:

* получение списка пользователей;
* получение конкретного пользователя;
* создание пользователя;
* обновление данных пользователя;
* удаление пользователя;
* регистрация пользователя;
* авторизация пользователя;
* негативные сценарии;
* проверка HTTP status codes;
* проверка данных в response body.

## Тестовые сценарии

### GET — получение списка пользователей

Проверяется получение списка пользователей.

**Проверки:**

* HTTP status code;
* наличие пользователей в ответе;
* корректность структуры JSON;
* наличие необходимых полей в объекте пользователя.

Ожидаемый результат:

```text
Status Code: 200 OK
```

---

### GET — получение пользователя

Проверяется получение конкретного пользователя по его ID.

**Проверки:**

* HTTP status code `200`;
* наличие объекта пользователя;
* соответствие полученного ID запрашиваемому;
* наличие основных пользовательских данных.

Также проверяется негативный сценарий с несуществующим пользователем.

Ожидаемый результат:

```text
Existing user → 200 OK
Non-existing user → 404 Not Found
```

---

### POST — создание пользователя

Проверяется создание нового пользователя с помощью `POST`-запроса.

В запрос передаются пользовательские данные в JSON-формате.

**Проверки:**

* HTTP status code;
* наличие созданного пользователя в response;
* корректность переданных данных;
* наличие `id` и других возвращаемых API данных.

Ожидаемый результат:

```text
Status Code: 201 Created
```

---

### PUT — обновление пользователя

Проверяется обновление существующего пользователя.

**Проверки:**

* HTTP status code;
* наличие обновленных данных;
* соответствие данных отправленному request body;
* наличие времени обновления, если оно возвращается API.

Ожидаемый результат:

```text
Status Code: 200 OK
```

---

### DELETE — удаление пользователя

Проверяется удаление пользователя.

**Проверки:**

* HTTP status code;
* корректность выполнения DELETE-запроса.

Ожидаемый результат:

```text
Status Code: 204 No Content
```

---

### POST — регистрация пользователя

Проверяется успешная регистрация пользователя с корректными данными.

**Проверки:**

* HTTP status code;
* наличие `id`;
* наличие `token`;
* корректность структуры response.

Ожидаемый результат:

```text
Status Code: 200 OK
```

---

### POST — негативный сценарий регистрации

Проверяется попытка регистрации без обязательных данных.

**Проверки:**

* API возвращает ошибку;
* корректный HTTP status code;
* наличие сообщения об ошибке в response body.

Ожидаемый результат:

```text
Status Code: 400 Bad Request
```

---

### POST — авторизация пользователя

Проверяется успешная авторизация с валидными учетными данными.

**Проверки:**

* HTTP status code;
* наличие authentication token;
* корректность структуры JSON response.

Ожидаемый результат:

```text
Status Code: 200 OK
```

---

### POST — негативный сценарий авторизации

Проверяется авторизация без обязательного параметра.

**Проверки:**

* возвращается `400 Bad Request`;
* response содержит сообщение об ошибке;
* API корректно обрабатывает некорректный запрос.

---

## Типы проверок

В тестах используются следующие виды assertions:

### Status Code

Проверяется HTTP-код ответа:

```python
assert response.status_code == 200
```

### Response Body

Проверяется содержимое JSON-ответа:

```python
response_json = response.json()

assert response_json["data"]["id"] == user_id
```

### Проверка полей

Проверяется наличие обязательных полей:

```python
assert "id" in response_json["data"]
assert "email" in response_json["data"]
```

### Проверка данных запроса и ответа

Для POST/PUT-запросов проверяется, что API корректно обработал отправленные данные.
